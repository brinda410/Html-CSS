# HTML & CSS Fundamentals 🚀

Welcome to my repository dedicated to mastering frontend fundamentals! This is a collection of mini-projects, structured exercises, and responsive layout designs built using pure HTML and CSS. It tracks my learning journey from basic structural tags to advanced styling and layout techniques.

## 📁 Repository Structure

The repository is organized into specific modules focused on core HTML and CSS concepts:

### 🛠️ HTML Exercises
* **`Html-1/`**: Practice files covering foundational HTML elements like **Forms**, **Tables**, **Lists**, and text formatting tags.
* **`Html-2/`**: A creative lyric page utilizing structural and formatting tags such as `<a>`, `<pre>`, `<hr>`, and `<br>`.
* **`Html-3/`**: A multimedia-focused page incorporating a custom **Favicon** and embedded **Audio** elements.

### 🎨 CSS Styling & Layouts
* **`CSS-1/`**: A fun, pure-CSS **Smiley Face** illustration showcasing basic shapes, positioning, and border-radius properties.
* **`CSS-2/`**: A functional **Traffic Light** simulation built using advanced CSS layouts and styling.
* **`CSS-3/`**: Practical implementations and layout structures using **CSS Grid**.
* **`CSS-4/`**: Smooth transitions, keyframes, and custom **CSS Animations**.
* **`CSS-5/`**: Fully responsive designs using **Media Queries** to ensure a mobile-friendly layout.
* **`FlexBox/`**: Hands-on exercises mastering alignment, direction, and flexible layouts using **CSS Flexbox**.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic elements, structure, forms, and multimedia.
* **CSS3:** Flexbox, CSS Grid, Custom Animations, Media Queries, and absolute/relative positioning.

## 🚀 How to Run the Projects Locally

If you'd like to explore these mini-projects on your local machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/brinda410/Html-CSS.git](https://github.com/brinda410/Html-CSS.git)
    ```
2.  **Navigate to the directory:**
    ```bash
    cd Html-CSS
    ```
3.  **Open any project:**
    Navigate into any folder (e.g., `FlexBox` or `CSS-4`) and open the `index.html` file directly in your preferred web browser, or use an extension like *Live Server* in VS Code.
